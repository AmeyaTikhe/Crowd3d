A multi-view labeling tool based on VIA 1.0.4 
(http://www.robots.ox.ac.uk/~vgg/software/via/) is provided for image annotating. 

The multi-view labeling tool contains two parts: 
the html-based interactive canvas and the “projection.js” part for coordinate projection across views.

The left 3 canvases are used to show the labels or select regions to annotate.
The right 3 canvases are used for annotating, which is similar to the PETS2009 labeling tool. 

See the pdf instruction document in the PETS2009/labeling_tool folder.
